# Musical Scales & Pentatonic Table

Интерактивная русскоязычная таблица 30 мажорных и минорных тональностей. Показывает ступени гаммы, знаки при ключе и ноты пентатоники.

## Возможности

- 15 мажорных и 15 параллельных минорных тональностей;
- жёлтая маркировка пяти нот пентатоники;
- сортировка по тонике, типу, нотам и знакам при ключе;
- адаптация для небольших экранов.
